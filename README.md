# Лабораторная работа №5 — DOM, события, формы

Репозиторий проекта **dom-store-zhunosov**.

## Как открыть проект

Для запуска проекта достаточно открыть файл `index.html` в любом современном браузере.
Также проект можно запустить через локальный сервер (например, расширение Live Server в VS Code).

## Обработка событий в проекте

В данном приложении обработаны следующие ключевые события DOM API:
1. **submit на форме добавления (#add-product-form):** перехватывается стандартное поведение отправки формы через event.preventDefault(), запускается валидация полей в DOM и добавление объекта в экземпляр Store.
2. **click с использованием делегирования событий (Event Delegation) на <tbody>:** один общий слушатель обрабатывает клики по кнопкам «Удалить» на любом элементе списка товаров через проверку event.target.dataset.action.
3. **change с делегированием событий на <tbody>:** отслеживает изменение количества товара в инпутах qty-input и сразу пересчитывает стоимость конкретного товара и итоговый 	otal без перезагрузки страницы.
